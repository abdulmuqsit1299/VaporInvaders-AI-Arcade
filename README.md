## 📌 Executive Overview

**VaporInvaders** is a high-performance, retro 80s arcade web application that merges classic Space Invaders gameplay mechanics with a live-streamed Pakistani and Indian (Desi) soundtrack engine. Highlighting dynamic canvas rendering, CRT visual effects, and optimized background audio processing, this project showcases rapid agentic prototyping and full-stack AI-driven web development.

---

## 🚀 Key Features & Custom Innovations

- 👾 **Retro Arcade Gameplay:** Classic Space Invaders game engine built with custom collision detection, score tracking, alien wave scaling, and CRT scanline visualizers.
- 🎵 **Desi Music Broadcast Engine:** Integrated YouTube API pipeline to stream top Pakistani (Coke Studio, Pop) and Indian classics seamlessly during gameplay.
- ⚡ **Audio-First Optimization:** Streamlined UI rendering designed to isolate heavy video streams into high-FPS audio streams, maintaining max game frame rates.
- 🎨 **80s Synthwave Aesthetic:** Custom neon theme, cassette tape deck UI animations, and dynamic 64-band audio spectrum analyzer.
